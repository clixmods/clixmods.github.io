## ADSearch - Montpellier

---

À l'attention d'Antony
ADSearch
Montpellier

Objet : Candidature au poste de Développeur Java Angular - CDI

Madame, Monsieur,

Diplômé d'un BUT IAMSI à l'IUT de Montpellier-Sète et fort de deux années d'expérience en développement C# et .NET au sein du Studio La Moutarde, je me permets de vous adresser ma candidature pour le poste de Développeur Java Angular, bien que mon profil s'écarte des 5 ans d'expérience requis.

Mon parcours m'a permis de développer une solide maîtrise de l'architecture logicielle moderne. J'ai conçu une application web complète en Blazor avec FastEndpoint pour les API REST et SQL Server pour la gestion des données. Cette expérience m'a familiarisé avec l'architecture MVC, l'injection de dépendances et le développement d'API robustes - des compétences transférables à Java/Spring. Ma participation à la production du jeu Terra Memoria m'a confronté aux exigences de qualité et de performance attendues en environnement professionnel.

Je suis conscient que Java et Angular ne font pas partie de mon stack actuel. Cependant, mon parcours autodidacte initial témoigne de ma capacité à apprendre rapidement de nouvelles technologies. La transition de C# vers Java est facilitée par leurs syntaxes similaires, tandis que mon expérience frontend avec Blazor me fournit une base pour aborder Angular.

Disponible immédiatement et basé à Montpellier, je serais ravi d'échanger avec vous sur la manière dont mon profil pourrait correspondre à vos besoins.

Dans l'attente de votre retour, je vous prie d'agréer, Madame, Monsieur, l'expression de mes salutations distinguées.

Clément GARCIA
